# 商品管理システム

## 概要
サーブレットとJSPを使用して作成した、商品管理システムです。  
ログイン後、商品一覧の表示、商品登録、商品編集および商品削除が行えます。

---

## 使用技術
- Java
- Jakarta Servlet
- JSP
- MySQL
- Apache Tomcat 10

---

## 起動方法
1. MySQL を起動し、`product_management` データベースを用意します
2. Tomcat を起動します
3. ブラウザで以下のURLにアクセスします

http://localhost:8080/development_project/login

## 機能一覧
- ログイン機能
- 商品一覧表示
- 商品登録機能
- 商品編集機能
  - 既存商品の情報を編集可能
  - カテゴリをプルダウンから選択
  - 入力値チェック（エラーメッセージ表示）
- 商品削除機能
  - 削除確認画面の表示
  - 確認後に削除処理を実行
- カテゴリ選択（DBから取得）

---

## 動作確認手順
1. ログイン画面にアクセスする
2. 正しいID・パスワードでログインする
3. 商品一覧画面が表示されることを確認する
4. 「商品登録」リンクから商品登録画面に遷移する
5. 正常な値を入力して商品を登録する
6. 登録後、商品一覧に反映されていることを確認する
7. 商品一覧画面の「編集」をクリックする
8. 編集画面に現在の商品情報が表示されていることを確認する
9. 商品情報を変更して保存し、一覧画面に反映されていることを確認する
10. 価格や在庫に負の値を入力し、エラーメッセージが表示されることを確認する
11. 商品一覧画面の「削除」をクリックする
12. 削除確認画面が表示されることを確認する
13. 「はい」を選択すると商品が削除され、一覧から消えることを確認する
14. 不正な商品IDで操作した場合、エラーメッセージが表示されることを確認する
